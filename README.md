# League Damage Simulator

Projeto desenvolvido para simular cálculos de dano inspirados no League of Legends.

O sistema possui diferentes simuladores de combate utilizando HTML, CSS e JavaScript, com foco em:
- dano crítico
- penetração de armadura
- letalidade
- itens
- quantidade de ataques necessários para eliminar um inimigo

---

# Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
